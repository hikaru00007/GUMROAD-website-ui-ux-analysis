00 — The mechanic

The shadow is revealed, not added

Hover any solid object in this sheet. The element travels up-and-left and a hard, zero-blur shadow appears in the space it vacated. The offset always equals the travel. Drag the sliders to break the rule and feel it stop working.

01 — Color

Six brights, one accent

Flat, unmodulated, full saturation. No gradients, no tint ramps. The neutrals are warm — #f4f4f0 and #242423 — which is what keeps the brights from vibrating. Contrast ratios below are computed live.

The RGB-triplet trick Architecture

Colors are stored as space-separated channels, not hex, so alpha is applied at the consumption site. That is how ten variables carry an entire theme — muted, subtle, and borders are free derivatives, not hand-picked values.

12 — Motion

13 — Dark mode

Ten variables, no toggle

Gumroad ships prefers-color-scheme only — there's no manual switch. The entire dark theme is ten overrides in one media query. Notably, --accent is not one of them: pink is theme-invariant by design, which is why it detonates on #242423.

The overrideEntire dark theme
@media (prefers-color-scheme: dark) {
  :root, :host {
    --body-bg: #242423;        /* was #f4f4f0 */
    --primary: 221 221 221;    /* was 0 0 0     */
    --contrast-primary: 0 0 0;
    --color: 221 221 221;      /* was 0 0 0     */
    --filled: 0 0 0;           /* was 255 255 255 */
    --neutral-color: 221 221 221;
    --neutral-filled: 0 0 0;
    --neutral-border-alpha: .35;
    --contrast-filled: 221 221 221;
    --contrast-black: 221 221 221;
    --border-alpha: .35;       /* borders weaken, they don't change color */
    /* --accent is deliberately absent. */
  }
}

14 — The rules

Ten things that make it tick

The minimum viable kit. Break one and the system stops reading as intentional.

1px black borderOn every solid element. It's the load-bearing part of the aesthetic, not a finish.

Zero blur, always4px 4px 0, never 4px 4px 8px rgba(). Blur reads generic.

Offset equals travelMove 4px, reveal 4px. The relationship is the whole trick.

Flat colorSix brights at full value. No gradients, no tint ramps, no 50-shade grays.

Pink means interaction#ff90e8 and nothing else. One accent, used relentlessly.

Display weight 400Bold heroes give you generic neobrutalism. Let the border be loud.

Warm neutrals#f4f4f0 / #242423. True gray lets the brights vibrate.

sm corners, full pillsrounded-sm for cards. rounded-full only where it's semantically a pill.

150ms, transform onlyNothing above 300ms. Animating shadows destroys the hard edge.

Respect reduced motionEvery animation dies under prefers-reduced-motion.
